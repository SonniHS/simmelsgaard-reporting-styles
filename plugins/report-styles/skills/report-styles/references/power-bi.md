# Power BI

The same styles in Power BI: a report theme per style and mode, and the IBCS Deneb templates re-coloured per
style. Both are generated by `scripts/build_styles.py` from the token files; never edit them by hand.

## Themes

`../style-<id>/assets/power-bi/<id>-pbi-theme-<light|dark>[-cvd].json`. Import one in Power BI Desktop (View →
Themes → Browse for themes), or set it as the custom theme of a PBIR report. Every style, IBCS included, has all
four (light, dark, and each with the colour-blind-safe set).

| | IBCS | Showcase | Soft | Graphic | Annual | Wallboard | Contrast | Terminal |
|---|---|---|---|---|---|---|---|---|
| Page, visuals | page and visual backgrounds from the tokens | solid panels with a hairline border, 12 px radius | panels with radius and a soft shadow (light) | no visual backgrounds or borders | tinted panels, no borders | panels on a contrasting page | white or black panels | flat panels |
| Fonts (installed faces) | Segoe UI | Segoe UI, Semibold figures | Segoe UI, Bold figures | Georgia titles, Segoe UI text | Segoe UI, Light figures | Segoe UI Semibold, Black figures | Segoe UI, Bold titles | Consolas |
| Data colours | AC, PY, then neutral greys | AC (amber), PY (slate), greys | AC, PY, greys | AC (ink), PY, greys | AC (aubergine), PY, greys | AC, PY, greys | AC (black or white), PY, greys | AC, PY, greys |
| Impact | `good` / `bad` / `neutral` from the mode (the CVD theme swaps them) | | | | | | | |

Power BI themes take no web fonts and no gradients: each style maps to installed faces (table). Power BI has no
runtime light/dark or style switch; choose a theme per report, or keep a page group per style behind bookmarks.
The report layout follows [page-layout.md](page-layout.md): the same visual positions in every style, so
changing the style is a theme swap.

## Deneb

The chart templates are the `ibcs-power-bi` plugin's (`ibcs-deneb`). Each style ships
`../style-<id>/assets/deneb/<id>-<mode>.overrides.json`, which re-colours them through that skill's sync script:

```
python3 -I <ibcs-deneb>/scripts/sync_tokens.py --overrides <style-dir>/assets/deneb/soft-light.overrides.json --out ./deneb-soft-light
python3 -I <ibcs-deneb>/scripts/sync_tokens.py --overrides <style-dir>/assets/deneb/soft-light.overrides.json --variant cvd --out ./deneb-soft-light-cvd
```

The output is a `templates/` and `config/` folder with every template's `ibcs*` params set to the style
(scenario colours, impact colours, text, background, axis, highlight, font). Template structure, polarity and
notation do not change. Showcase's hue encoding for AC against one reference comes through the AC and PY
colours; PL and FC keep their outline and hatch.

## Checking with ibcs_lint

`ibcs-review`'s `ibcs_lint.py theme <file>` checks a theme against strict IBCS. On a style theme it reports
the style's documented relaxations as findings: that is expected, and each style skill lists which ones. Any
other finding is a defect.
