# simmelsgaard-reporting-styles

Presentation styles for IBCS®-based business reports, as a Claude Code plugin: IBCS (for the CFO), Showcase (for
Marketing), Soft (for HR / People) and Graphic (for Communication), in light and dark, with the same numbers and one
page layout in every style. The plugin arrives with release 1.0.0.
