# report-styles

Four presentation styles for IBCS®-based reports, each in light and dark, with the same numbers and one page
layout in every style. Requires the `ibcs` plugin from simmelsgaard-reporting-skills (installed as a
dependency).

## Install

```
/plugin marketplace add SonniHS/simmelsgaard-reporting-skills
/plugin marketplace add SonniHS/simmelsgaard-reporting-styles
/plugin install report-styles@simmelsgaard-reporting-styles
```

## Skills

- [`report-styles`](skills/report-styles/SKILL.md) — the system: choosing, pre-select or switch, light/dark, the
  shared layout, the reconcile test, tokens and brand, Power BI, adding a style.
- [`style-ibcs`](skills/style-ibcs/SKILL.md) — IBCS · for the CFO, the reference.
- [`style-showcase`](skills/style-showcase/SKILL.md) — Showcase · for Marketing.
- [`style-soft`](skills/style-soft/SKILL.md) — Soft · for HR / People.
- [`style-graphic`](skills/style-graphic/SKILL.md) — Graphic · for Communication.

## Examples

- "Give this KPI page a Soft version for the HR team, same numbers."
- "Add a style switch with IBCS and Showcase, and a dark mode."
- "Put our brand colour into the Showcase style."
- "Make the Power BI report match the Graphic style in dark."
