# Report styles — React reference components

React 18 + SVG components for the report styles (IBCS, Showcase, Soft, Graphic, Annual, Wallboard), written to the `report-styles` skill. Copy
`src/report-styles` into your app and extend. MIT.

```tsx
import "./report-styles/styles/index.css";            // fonts (self-hosted), tokens, skeleton, styles
import { StyleProvider, TopBar, KeyFiguresPage, SAMPLE } from "./report-styles";

<StyleProvider styles={["ibcs", "soft"]} theme="system">   // one id = pre-selected, no switch
  <TopBar brand="Sample Co" />
  <KeyFiguresPage data={SAMPLE} />
</StyleProvider>
```

| File | What it is |
|---|---|
| `viewModel.ts` | the hard rules (`relVar`, `tone`, `dir`, `fmt`, `fmtDelta`, `keep`) and the Key figures view model |
| `state.ts` | pure switch rules: offered styles, `style=` / `theme=` / legacy `variant=`, arrow keys |
| `StyleProvider.tsx` | applies style, theme and CVD to the document and the URL; follows the system theme |
| `switches.tsx` | `StyleSwitch`, `ThemeSwitch`, `CvdToggle`, `TopBar` (radio groups, keyboard) |
| `ReportPage.tsx` | the shared page skeleton, `KpiTile`, `KeyMessage`, `NotationKey`, `ChartSlot` |
| `parts/<id>.tsx` | each style's two cards (chart grammar, subtitles, legend, words) |
| `tokens.generated.ts`, `styles/tokens-<id>.css` | generated by `scripts/build_styles.py`; do not edit |
| `styles/base.css`, `styles/<id>.css`, `styles/fonts.css` | skeleton geometry, style rules, self-hosted fonts |

Your own data: pass a `KeyFiguresInput` (KPIs, a time series, a structure; titles, units and the AC/PY labels are
yours — see `fixtures.ts` for a people page) to `<KeyFiguresPage data={…} />`. A different page: build your view
model with the same helpers, give every number a `data-k`, and render your own skeleton in the same order.

**In a Vite app:** copy `src/report-styles` into `src/`, import `report-styles/styles/index.css` once, add the
dependencies of `package.json` (React and the `@fontsource` packages), and give your `tsconfig.json`
`"lib": ["ES2022", "DOM", "DOM.Iterable"]` and `"types": ["vite/client"]`. Vite bundles the fonts from the CSS
imports; nothing else to configure. Run `scripts/check-previews.mjs` on the built `dist/` (see its header) after
exposing `window.__REPORT_STYLES__` in your entry as `previews/main.tsx` does.

```sh
npm ci
npm run typecheck
npm test            # view-model rules, switch state, reconcile of every style on desktop and phone
npm run previews    # previews/dist; serve previews/ over http (fonts do not load from file://)
```
