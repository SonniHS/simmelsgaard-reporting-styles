# Changelog

All notable changes to this marketplace and its plugin. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- CI lints every style's DESIGN.md with Google's linter (`@google/design.md` 0.4.0); any error or warning fails.

### Changed
- DESIGN.md: every token is used by a component. Added components for the page, card subtitle, divider, highlight,
  PL and FC marks, the chart axis, grid and labels, and the CVD variances, and a `-dark` variant of every component.
  A transparent card or tile names the page colour it shows, so contrast is checked against what is drawn.

## [1.4.0] - 2026-10-27

### Added
- **A DESIGN.md for every style** (`style-<id>/assets/DESIGN.md`) in the
  [google-labs-code/design.md](https://github.com/google-labs-code/design.md) format: tokens in the front matter for
  both themes, the eight sections, and the relaxed IBCS rules as do's and don'ts; non-IBCS styles say plainly that they
  are not IBCS-compliant. Generated by `build_styles.py`, kept current by `--check`, and checked against the format's
  rules (colours, dimensions, references, section order) by the repository tests.

### Fixed
- Playground: the KPI editor is a small form per tile instead of a seven-column table, so labels and numbers are no
  longer cut off; the report is found when the host drops the `?embed=1` query (detected by its frame); a report
  that does not start in its frame now says so instead of waiting forever.

## [1.3.0] - 2026-10-23

### Added
- Style **Contrast · for Accessibility** (`style-contrast`): AAA contrast in both modes (text 7:1, marks 4.5:1),
  Atkinson Hyperlegible, 2 px borders, a direction glyph on every variance so colour is never the only cue.
- Style **Terminal · for Engineering** (`style-terminal`): a monospace command-line page, 1 px boxes, a table with
  inline bars, an amber accent; dark-first.
- `meta.level: "AAA"` in the token contract: the build then enforces 7:1 for text and 4.5:1 for marks.
- **Playground** (`previews/playground.html`, [docs/playground.md](docs/playground.md)): every style, theme and width on
  your own numbers — presets, a form for every field, JSON, stress buttons — with the report's checks shown live.
- A stress fixture (long names, six-digit values, 24 months) and the 820 px width in the browser check and CI.

### Changed
- **Only the IBCS style follows the IBCS® Standards**; the docs and skills now say so plainly. The other styles borrow
  elements of the IBCS notation and relax its presentation rules on purpose, so they are not IBCS-compliant.
- Layout robustness, found with the playground: the two cards stack below 1024 px; value and axis labels thin by the
  space they have (not only on phones); long names end in "…" with a tooltip; KPI values shrink to fit their tile;
  line-end labels never collide; the first and last columns are inset so their labels stay on the card.
- The shared set: every time point's Δ% that fits, and always the largest, the smallest and the last.

## [1.2.0] - 2026-10-23

### Added
- Style **Annual · for Investors** (`style-annual`): the key-figures spread of an annual report — a tinted message
  band, light-weight numerals, AC columns and bars with a PY marker line, numbered callouts; aubergine and gold.
- Style **Wallboard · for Operations** (`style-wallboard`): a screen read from a few metres — very large figures,
  high contrast, thick columns and bars, variances as large chips, few labels; usually shown dark.
- Both in light and dark with colour-blind-safe sets, Power BI themes, Deneb overrides, DTCG tokens, documented
  relaxations, and covered by the reconcile, same-scale, layout and browser checks.

## [1.1.0] - 2026-10-23

### Added
- IBCS Power BI assets for light too (`ibcs-pbi-theme-light.json`, `-light-cvd`, `ibcs-light.overrides.json`), in the
  web style's screen-tuned colours: every style now has all four themes and both overrides files in this repository.

### Changed
- IBCS structure card: when the names leave too little room, they move onto their own line above the bars before
  any column is dropped, so the absolute ΔPY column stays on narrower cards. On phones the names always sit above
  the bars, and long names are no longer shortened.
- Soft structure card on phones: names above the bars, so the bars use the full width and, at the shared scale
  (CH 4.1), the time chart above gets a readable height.

## [1.0.0] - 2026-10-23

### Added
- Plugin `report-styles` with the skills `report-styles`, `style-ibcs`, `style-showcase`, `style-soft` and
  `style-graphic`: four presentation styles for IBCS-based reports (IBCS for the CFO, Showcase for Marketing, Soft
  for HR / People, Graphic for Communication), each in light and dark, with a colour-blind-safe set.
- One page layout for every style (header, key message, four KPI tiles, time card, structure card, footer) and one
  view model, so every style shows the same numbers in the same places.
- A style switch (`style=`, pre-select one or offer several, per-app labels) and a theme switch (`theme=`, following
  the system until the reader picks; print always light), both keyboard-accessible.
- Same unit, same scale on every page (IBCS CH 4.1): one scale registry, measured in the browser.
- Token contract (JSON Schema) and `build_styles.py`: contrast, impact-colour and notation guardrails in both modes;
  generates TypeScript and CSS tokens, DTCG exports, Power BI themes (light, dark, CVD) and overrides for the
  ibcs-deneb templates.
- Tested React 18 + SVG reference components with self-hosted OFL fonts, a preview app and `check-previews.mjs`
  (reconcile, layout, scale, label collisions, fonts, themes, keyboard), usable on any built app.
- Input for any key-figures page: KPI kinds `amount`, `count`, `rate`, `score`; polarity per measure; a totals check.
- Docs: getting started, choosing a style, gallery, web apps, Power BI, testing, troubleshooting, design.
